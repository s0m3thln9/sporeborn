# Проверка изменений Unity

1. Прочитай `AGENTS.md`, `docs/development.md` и относящийся к задаче раздел GDD. Определи ожидаемое поведение и затронутые ассеты по Git diff.
2. Проверь, что у добавленных ассетов есть `.meta`, удалённые ассеты удалены вместе с `.meta`, а у перемещённых ассетов сохранены GUID. Если ссылки в сцене или префабе изменились, проверь целевые ассеты, обязательные поля Inspector и отсутствующие скрипты. Для пакетных ссылок учитывай зависимости из manifest.
3. Если Unity-проект и совместимая версия редактора доступны, открой затронутые сцены и префабы. Проверь ошибки компиляции, импорта и Console. Отдельно укажи ошибки, которые воспроизводятся до изменения.
4. Пройди изменённый путь в Play Mode через обычное действие игрока. Проверь успешный случай, ожидаемый отказ и повтор, если он может изменить состояние. Для эпизода упаковки используй утверждённые условия из GDD и меняй сценарий под фактический diff.
5. Запиши проверенные ассеты, шаги воспроизведения и результаты. Для каждой проверки, которую нельзя выполнить, укажи причину. Если Unity-проект ещё отсутствует, заверши доступные статические проверки.

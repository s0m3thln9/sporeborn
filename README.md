# Sporeborn

Одиночный 3D-симулятор от первого лица. Игрок вручную проходит цикл выращивания шампиньонов, от подготовки смеси до продажи урожая. Для MVP запланированы одна комната, один многоразовый контейнер и три партии на демонстрацию.

В сцене `Workshop` можно пройти первый сценарий MVP: поднять гриб с площадки, отпустить его или положить в коробку. Порядок запуска описан в [документации по разработке](docs/development.md).
